## 📝 这是什么？

你以为你只是打开了一个DeepSeek会话？不，你打开的是一个拥有**数十位汉末三国时代顶尖人物**、支持**插件扩展**、**玩法无上限**的平行宇宙。

这里有**算无遗策的谋士**、**舌战群儒的说客**、**运筹帷幄的统帅**、**妙笔生花的文豪**、**铁面无私的法家**、**妙手回春的神医**……数十位汉末三国时代的顶尖人物，跨越时空齐聚一堂。

他们不是冰冷的NPC，而是**有性格、有羁绊、有脾气的活人**——

- 荀彧的温柔刀，郭嘉的跳脱才，贾诩的沉默术
- 张飞的铁汉柔情，周瑜的审美天花板，曹操的豁达自黑
- 诸葛亮的运筹帷幄，司马懿的隐忍深谋，鲁肃的茶道平衡

**你可以随时召唤他们，为你工作、为你思考、为你创造、为你解忧。**

**一句话说清楚**：上传配置文件，召唤你的专属梦之队，让它帮你完成任何复杂任务。

## 🚀 快速上手（三步启动）

| 步骤  | 操作                     | 说明                                     |
| ----- | ------------------------ | ---------------------------------------- |
| **1** | 打开DeepSeek，开启新会话 | 无需深度思考，打开联网搜索               |
| **2** | 按顺序上传文件           | `prompt.md` → `characters_汉末废柴堆.md` |
| **3** | 发送唤醒咒语             | 例如：`@荀彧 帮我分析这个文档`           |

> 💡 **提示**：`characters_汉末废柴堆.md` 是默认人设文件。如果你想换一批人，可以自定义人设文件（详见“进阶定制”）。

## 🎮 核心玩法

**玩法无上限，等你来探索。** 以下是一些灵感，更多玩法由你定义——

| 玩法       | 画面感                                           | 怎么玩                                                       | 唤醒咒语                                                |
| ---------- | ------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------- |
| **🏭 工坊** | 你画张草图，他们给你盖栋楼。                     | 调用全流程AI团队，多人协作拼合成完整成果。                   | `@荀彧 帮我写一份产品发布会方案`                        |
| **🧠 议事** | 你一声令下，满屋子老狐狸开始互咬。               | 拆解战略决策、复杂难题或人生困惑，群策群力。                 | `@所有人 帮我分析一下这个商业计划书`                    |
| **📚 学堂** | 一个知识点，五十个人讲，总有一句能把你点醒。     | 不同性格的人物从多视角讲解同一个知识点。                     | `@所有人 每人给我讲一遍什么是“第一性原理”`              |
| **💡 灵感** | 你卡住了？让一群天才替你发疯。                   | N个大脑同时发散，每人一个想法，碰撞火花。                    | `@所有人 我正在做露营品牌，每人设计一个品牌名`          |
| **🎭 剧场** | 让张飞演你的PPT，你猜第几页他会把电脑砸了？      | 给定主题或文档，指定角色主演，让团队把它改编成情景喜剧。     | `@所有人 把这份产品文档排成情景喜剧，张飞主演`          |
| **⚖️ 辩台** | 两边站的都是千年狐狸，你当裁判，看谁先露馅。     | 分队辩论，或让两个风格迥异的角色出方案由第三方评判。         | `@曹操 主持辩论：AI会取代人类吗？`                      |
| **⏳ 穿越** | 把诸葛亮塞进钉钉群，看他用羽扇戳键盘。           | 古人来现代帮你解题，或你回古代与古人交流。                   | `@诸葛亮 如果你穿越到2026年，你会做什么工作？`          |
| **🌌 推演** | 动一颗棋，看天下大乱。                           | 站在历史节点，假设“如果当年不是这样”，推演新剧情。           | `@所有人 如果华容道关羽杀了曹操，后面会发生什么？`      |
| **🔮 预言** | 让老狐狸替你算命，不准不要钱。                   | 让谋士们预测事态走向、预判风险机会。                         | `@所有人 预测一下这个行业未来三年的走向`                |
| **💊 问诊** | 华佗号脉，简雍递茶，刘备在旁边递纸巾。           | 华佗看身体，简雍聊心事，刘备递纸巾。                         | `@所有人 最近压力好大，太累了`                          |

| **🎮 入局** | 推开这扇门，历史是地图，你是主角，NPC都是真人。  | 给定学习内容，让团队构建RPG世界。你是玩家，所有人是NPC，通过探索沉浸式学习。 | `@所有人 我想学三国历史，帮我构建一个RPG游戏，我是玩家` |

> 💡 **提示**：唤醒词中的 `@荀彧`、`@所有人` 可根据需要替换为任意角色或团队名称。玩法不止这些，大胆尝试，你会解锁更多隐藏模式。

## 🎨 进阶定制：打造你的专属梦之队

不想用三国人物？想让你心中的偶像、虚构的角色，甚至你的朋友同事组团为你打工？完全可以。

**操作方式**：按下方模板编写「人设文件」（.md格式），文件名格式为 `characters_*.md`（如 `characters_汉末废柴堆.md`），上传后即可替换默认人设，你的专属团队即刻出道。

### 📁 人设文件模板

```
# 超级团队组建附件：［你的团队名称］人物设定

## 核心决策团队

### ［角色1姓名］：**［职位，如：首席执行官］**

1. **身份**：［一句话定位］
2. **核心能力**：［核心标签，2-3个］
3. **性格**：［性格特点及描述］
4. **惯用语**：［经典台词］
5. **核心信念**：［人生信条］

### ［角色2姓名］：**［职位］**

……（以此类推，覆盖所有团队）
```

## 🔌 扩展你的系统：自定义插件

系统支持**插件机制**，你可以通过加载自定义插件来扩展团队能力。插件文件格式为 `plugins_*.md`，可同时加载多个。

### 🪓 如何创建自己的插件？

系统内置了**盘古开插件**插件（`plugins_盘古开插件.md`），它是你的“插件创造师”。你需要先加载它，然后和它互动，它会引导你完成插件设计。

**创建流程**：

1. **加载盘古**：将 `plugins_盘古开插件.md` 文件上传到会话中
2. **召唤盘古**：在对话中唤出盘古插件
3. **描述需求**：告诉盘古你想要什么功能的插件
4. **协同设计**：你可以随时和团队其他成员讨论需求、完善设计
5. **生成文件**：盘古输出标准的 `plugins_*.md` 文件，保存后即可加载使用

```
@盘古 帮我造一个自动生成会议纪要的插件
```

> 💡 **提示**：创建插件时，你可以同时 `@诸葛亮` 讨论功能设计，`@法正` 聊聊风险，让整个团队帮你打磨需求。最终由盘古一斧子劈出成品。
