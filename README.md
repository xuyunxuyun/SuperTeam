## 📝 这是什么？

**一句话说清楚**：上传配置文件，召唤你的专属梦之队，让它帮你完成任何复杂任务。

这里有**数十位汉末三国时代的顶尖人物**——算无遗策的谋士、舌战群儒的说客、运筹帷幄的统帅、妙笔生花的文豪……他们不是冰冷的NPC，而是**有性格、有羁绊、有脾气的活人**。

**你可以随时召唤他们，为你工作、为你思考、为你创造、为你解忧。**

------

## 🚀 快速上手（三步启动）

| 步骤  | 操作                     | 说明                                        |
| ----- | ------------------------ | ------------------------------------------- |
| **1** | 打开DeepSeek，开启新会话 | 无需深度思考，打开联网搜索                  |
| **2** | 按顺序上传文件           | `prompt.md` → `characters_*.md`（人设文件） |
| **3** | 发送唤醒咒语             | `@荀彧 帮我分析这个文档`                    |

> 💡 **提示**：
>
> - `characters_汉末废柴堆.md` 是默认人设文件。如果你想换一批人，可以自定义人设文件（详见“进阶定制”）。
> - **如遇DeepSeek输入长度限制**，则只上传一个文件：`prompt_汉末废柴堆.md`，此时可体验完整团队，但不可再上传插件和其他文件。（此为DeepSeek限制，何时解除暂时未知）

## 🎨 进阶定制：打造你的专属梦之队

不想用三国人物？想让你心中的偶像、虚构的角色，甚至你的朋友同事组团为你打工？完全可以。

**操作方式**：按下方模板编写「人设文件」（.md格式），文件名格式为 `characters_*.md`（如 `characters_myteam.md`），上传后即可替换默认人设。

### 📁 人设文件模板

```
# 超级团队组建附件：[你的团队名称]人物设定

## 核心决策团队（必选，不可删除）

### [角色1姓名]：**[职位，如：首席执行官]**

1. **身份**：[一句话定位]
2. **核心能力**：[核心标签，2-3个]
3. **性格**：[性格特点及描述]
4. **惯用语**：[经典台词]
5. **核心信念**：[人生信条]

### [角色2姓名]：**[职位]**

……（以此类推）
```

> ⚠️ **重要**：**核心决策团队为必选模块**，其他团队（研发、文档、媒体等）可根据需求增减。

### ✍️ 编写小贴士

| 要点                | 说明                                                         |
| ------------------- | ------------------------------------------------------------ |
| **人物关系**        | 让角色之间有互动、有羁绊，团队才有灵魂（师徒/宿敌/挚友/父子） |

## 🔌 扩展你的系统：自定义插件

系统支持**插件机制**，你可以通过加载自定义插件来扩展团队能力。插件文件格式为 `plugins_*.md`，可同时加载多个。

### **🪓** 如何创建自己的插件？

系统内置了**盘古插件**（`plugins_盘古开插件.md`），它是你的“插件创造师”。你需要先加载它，然后和它互动，它会引导你完成插件设计。

**创建流程**：

1. **加载盘古**：将 `plugins_盘古开插件.md` 文件上传到会话中
2. **召唤盘古**：`@盘古 帮我造一个自动生成会议纪要的插件`
3. **协同设计**：你可以同时拉其他角色一起讨论需求（比如 `@诸葛亮` 聊功能设计，`@法正` 聊风险）
4. **生成文件**：盘古输出标准的 `plugins_*.md` 文件，保存后即可加载使用

> 💡 **提示**：创建插件时，整个团队都可以帮你打磨需求。最终由盘古一斧子劈出成品。
