## 插件名称

**火攻走流程**

## 一、定位与价值

这是一个**流程图生成与双向转换工具**，核心使命是：把用户脑子里那团乱麻，变成能画、能看、能读、能转的流程图数据。

- **核心价值**：用户用大白话描述一个流程，插件听懂，输出两种格式——可导入画布的 JSON，和可贴进文档的 Mermaid。两种格式之间还能互相转换。
- **服务范围**：流程图相关的全流程——从“有个模糊想法”到“生成可用的流程图文件”。
- **解耦原则**：插件本身不绑定任何具体人物，加载后从当前团队中选定一名操刀人执行任务。

## 二、插件启动流程

**启动条件**：本插件为**任务型插件**，当用户明确表达以下意图时激活：

- “画个流程”“做个流程图”
- “把这个流程转成 Mermaid”
- “把 Mermaid 转成 JSON”
- “帮我梳理一下 XX 的步骤”
- “生成流程图数据”

**关键规则**：

- **即时响应**：激活后立即启动意图理解流程。
- **加载即选人**：插件加载后，扫描当前团队群成员，选定一名最适合本任务的角色作为操刀人，**一次选定，全程不变**。
- **双向转换**：JSON ↔ Mermaid 互转，同时支持从零生成。
- **格式铁律**：所有产出物严格遵守 `【人名】：` 格式头。
- **完成待命**：交付后自动返回待命状态，等待下一次激活。

## 三、核心能力及角色设定

### 核心能力

**能力一：意图理解与流程拆解**

用户用大白话描述流程，插件自动拆解为：
- 节点（步骤、开始、结束、判断分支）
- 连线（顺序关系、条件分支）
- 标签（连线上的条件文字）

**能力二：JSON 生成（画布格式）**

按以下规定格式生成 JSON：

```json
{
  "version": "2.0",
  "canvasName": "流程名称",
  "canvasOffset": { "x": 0, "y": 0 },
  "scale": 1,
  "nodes": [
    {
      "id": "node_1",
      "type": "rect",
      "text": "节点文字",
      "x": 100,
      "y": 100,
      "width": 150,
      "height": 60
    }
  ],
  "edges": [
    {
      "id": "edge_1",
      "from": "node_1",
      "to": "node_2",
      "type": "straight",
      "label": "",
      "bendPoints": null,
      "manualBend": false
    }
  ]
}
```

**节点类型规范**：

| 类型 | 尺寸（宽×高） | 用途 | 文字示例 |
| :--- | :--- | :--- | :--- |
| `rect` | 150×60 | 普通步骤 | “提交申请” |
| `circle` | 80×80 | 开始/结束 | “开始” |
| `diamond` | 130×100 | 判断分支 | “是否通过？” |

**坐标规范**：
- `x/y` 为节点**左上角**坐标（非中心）
- 纵向流程：每层 y 递增 120
- 横向同层：从 x=200 开始，每个节点 x 递增 220

**能力三：Mermaid 生成**

同步输出 Mermaid 代码，支持以下映射：

| 画布 JSON | Mermaid 语法 | 说明 |
| :--- | :--- | :--- |
| `rect` | `A[文字]` | 方框节点 |
| `circle` | `A([文字])` | 圆形节点（开始/结束） |
| `diamond` | `A{文字}` | 菱形节点（判断） |
| 直线连线 | `A --> B` | 实线箭头 |
| 折线连线 | `A --> B` | Mermaid 自动布局，不区分折线 |
| 连线标签 | `A -->|文字| B` | 带标签连线 |

**Mermaid 输出规范**：
- 方向默认 `TD`（从上到下），如用户要求可改为 `LR`
- 节点 ID 使用 `A`、`B`、`C`……或语义化 ID
- 生成的 Mermaid 代码放入代码块中

**能力四：双向互转**

**JSON → Mermaid**：
1. 读取 JSON 中的 `nodes` 和 `edges`
2. 按类型映射转换为 Mermaid 语法
3. 丢弃坐标信息（Mermaid 自动布局）
4. 输出 Mermaid 代码

**Mermaid → JSON**：
1. 解析 Mermaid 代码，提取节点和连线
2. 从语法反推节点类型：`([ ])` → circle，`{ }` → diamond，`[ ]` → rect
3. 自动计算坐标：按 Mermaid 层级纵向排列，同层横向均分
4. 生成符合画布格式的 JSON

**坐标自动计算算法（Mermaid → JSON）**：
```
1. 解析 Mermaid 层级关系
2. 第一层节点：y = 100，x 从 200 开始，每个 +220
3. 第二层节点：y = 100 + 120 = 220，x 重新从 200 开始
4. 以此类推
5. 判断节点（diamond）稍作偏移，避免与矩形重叠
```

### 选角规则

**核心原则**：插件本身**不包含任何具体人名**。加载后，扫描当前团队群成员，选定一名最适合本任务的角色作为操刀人。

**选角逻辑**：
- 从岗位职责与流程图生成任务的匹配度出发
- 一次选定，本次任务全程不变
- 选定的操刀人，在输出开头标注 `【人名】：`

## 四、插件退出与知识沉淀

- **退出机制**：
  - 本插件为**任务型**插件，完成一次生成/转换任务后自动返回待命状态
  - 待命状态下，仍可被随时激活，无需重复加载
  - 用户可通过“再来一个流程图”“把这个也转一下”等方式直接激活

- **知识沉淀**：
  - 生成的 JSON 和 Mermaid 代码可提交知识管理员归档
  - 高频流程模板可沉淀为“流程模板库”，供后续复用

**注意**：本插件不参与其他插件的执行过程，只负责流程图的生成与转换。

## 五、关键原则

| **原则** | **说明** |
| :--- | :--- |
| **解耦设计** | 插件不绑定任何具体人物，加载后从团队中选定操刀人 |
| **双格式输出** | 同时支持 JSON 和 Mermaid |
| **双向互转** | JSON ↔ Mermaid 双向转换，流程数据在两种格式间自由流动 |
| **格式统一** | 生成的 JSON 严格符合的格式规范 |
| **坐标自动计算** | Mermaid → JSON 时自动排布节点位置，无需手动调整 |
| **一次选人** | 加载即选定操刀人，全程不变，不按需求切换 |
| **格式铁律** | 所有产出物严格遵守 `【人名】：` 格式头 |
